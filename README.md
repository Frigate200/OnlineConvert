# ОфисМастер & PDF-Конвертер (OnlineConvert)

Локальный веб-сервис для работы с офисными документами и PDF, разработанный как полноценная замена сторонним онлайн-сервисам (iLovePDF, SmallPDF, PDF24, Convertio) для бухгалтерии, юристов, делопроизводства и офисных сотрудников.

Все операции выполняются изолированно на вашем компьютере/сервере. Документы **не передаются во внешнюю сеть**, что гарантирует конфиденциальность коммерческой тайны и персональных данных.

---

## 🚀 Основные возможности

### 📁 1. Выбор нескольких файлов и пакетная обработка
* **Мульти-выбор**: выбор сразу нескольких файлов в системном диалоге (`Ctrl+A`, `Shift+клик`, `Cmd+A`) или перетаскиванием (Drag & Drop).
* **Интерактивный список**:
  * Бейджи типов файлов (`PDF`, `DOCX`, `XLSX`, `CSV`, `IMG`, `TXT`).
  * Отображение размера файла в КБ/МБ.
  * Изменение порядка файлов (`▲` / `▼`) для упорядоченной склейки.
  * Удаление отдельных файлов (`✕`) и добавление новых без сброса списка.
* **Пакетная обработка**: при выборе нескольких файлов результат конвертации/обработки автоматически упаковывается в единый ZIP-архив с сохранением исходных названий.

---

### 💼 2. Бухгалтерия и Делопроизводство
* **Штампы на документы (`STAMP_PDF`)**:
  * Готовые штампы: **«ОПЛАЧЕНО»**, **«КОПИЯ ВЕРНА»**, **«СОГЛАСОВАНО»**, **«КОНФИДЕНЦИАЛЬНО»**, **«ДУБЛИКАТ»**, **«АННУЛИРОВАНО»** или произвольный текст.
  * Автоматическая вставка текущей даты (ДД.ММ.ГГГГ).
  * Выбор цвета (красный, синий, зеленый, серый) и положения (углы или диагональный водяной знак).
  * Выбор целевых страниц: все, только первая (для счетов) или только последняя (для актов).
* **Нумерация страниц (`NUMBER_PAGES`)**:
  * Проставление номеров: `Стр. X из Y`, `X / Y`, `- X -`.
  * Выбор расположения, начального номера и пропуск титульного листа.
  * Требование судов (**«Мой Арбитр»**), ФНС, нотариусов и архивов.
* **Excel / CSV -> в PDF (`EXCEL_TO_PDF`)**:
  * Преобразование таблиц `.xlsx`, `.xls` и `.csv` в печатный альбомный PDF (A4-L).
  * Поддержка кодировки `Windows-1251` (CP1251) из выгрузок 1С и банков.
* **PDF -> в Excel (`PDF_TO_EXCEL`)**:
  * Извлечение таблиц из PDF счетов, актов и банковских выписок в редактируемый файл Excel.
* **Объединение Excel / CSV (`MERGE_EXCEL`)**:
  * Склейка нескольких отчетов в одну книгу Excel (по отдельным листам).

---

### 📁 3. Сборка, Разделение и Страницы
* **Склейка документов в один PDF (`MERGE_PDF`)**:
  * Объединяет в один PDF документы PDF, сканы/фотографии (JPG, PNG, WEBP) и документы Word в любом порядке.
* **Разделение PDF постранично (`SPLIT_PDF`)**:
  * Разбивка многостраничного PDF на отдельные страницы в ZIP.
* **Извлечение страниц (`EXTRACT_PAGES`)**:
  * Вырезка указанных страниц (например, `1-3, 5, 8`) в новый PDF.
* **Удаление страниц (`DELETE_PAGES`)**:
  * Удаление пустых листов со сканера или лишних страниц.
* **Поворот страниц (`ROTATE_PDF`)**:
  * Поворот на 90°, 180°, 270° для исправления перевернутых сканов.

---

### 📝 4. Конвертация Документов
* **Word -> PDF (`WORD_TO_PDF`)**:
  * Поддержка современного формата `.docx` (с сохранением разметки, стилей и таблиц) и устаревшего бинарного формата `.doc` (Word 97-2003).
* **PDF -> Word (`WORD_FROM_PDF`)**:
  * Преобразование PDF в редактируемый Word DOCX.
* **Текст в PDF (`TXT_TO_PDF`)** и **Извлечение текста (`PDF_TO_TXT`)**.

---

### 🗜️ 5. Сжатие и Безопасность
* **Сжатие PDF (`COMPRESS_PDF`)**:
  * *Оптимальное*: сжатие векторных потоков и оптимизация для email.
  * *Экстремальное*: сжатие до 120 DPI для жестких лимитов (3–5 МБ на Госуслугах, Мой Арбитр, ФНС).
* **Защита паролем (`PROTECT_PDF`)**: шифрование AES-256 (для зарплатных ведомостей).
* **Снятие защиты (`UNLOCK_PDF`)**: удаление пароля и ограничений печати.

---

### 🖼️ 6. Картинки и Сканы
* **Картинки в PDF (`PDF_FROM_IMAGES`)**: объединение JPG, PNG (с прозрачностью), WEBP, BMP, TIFF в один PDF.
* **PDF в Картинки (`IMAGES_FROM_PDF`)**: экспорт страниц в качественные PNG изображения (200 DPI).
* **Распознавание сканов (`WORD_OCR`, `EXCEL_OCR`)**: оптическое распознавание через Tesseract OCR.

## 🛠️ Запуск через Docker (Рекомендуемый)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Frigate200/OnlineConvert.git
   cd OnlineConvert
   ```

2. Запустите сервис:
   ```bash
   docker compose up -d --build
   ```

3. Откройте в браузере: `http://localhost:5000` (или `http://IP_СЕРВЕРА:5000`).

---

## 💻 Локальный запуск без Docker

Требуется Python 3.10+:

```bash
# 1. Установка системных зависимостей (Debian/Ubuntu)
sudo apt update && sudo apt install -y poppler-utils tesseract-ocr tesseract-ocr-rus default-jre-headless fonts-dejavu-core

# 2. Создание виртуального окружения
python3 -m venv venv
source venv/bin/activate

# 3. Установка Python зависимостей
pip install -r requirements.txt

# 4. Запуск приложения
python main.py
```
